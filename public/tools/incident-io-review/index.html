What is incident.io?

incident.io runs the whole incident in Slack or Microsoft Teams: declaring it, assigning roles, posting updates and writing the postmortem. The free Basic plan covers single-team on-call, one schedule, one workflow, two integrations and one public status page. Team ($15 per user a month billed annually, $19 monthly) adds multi-team on-call and unlimited integrations for $10 per user more; Pro ($25 plus $20 for on-call) adds custom post-incident flows, private incidents, an AI-native postmortem editor and SAML SSO.

Who it's best for

Engineering teams that already coordinate in Slack or Teams and want paging, response and postmortems in one product.

Why we rank it

It shares the highest G2 rating here (4.8/5 across 238 reviews), a free plan that includes on-call, and multi-team on-call with response for $25 a user a month on annual Team billing.

Pros and cons

Strengths

  • Free Basic plan includes single-team on-call and a public status page
  • Team with on-call totals $25 per user a month, billed annually
  • Rated 4.8/5 on G2 across 238 reviews

Watch-outs

  • On-call is an add-on: $10 per user on Team, $20 on Pro
  • Team allows 3 workflows; unlimited workflows need Pro
  • Every plan below Enterprise gets one public status page

Skip it if: You only need paging and schedules, not incident coordination; ilert Pro ($19) or PagerDuty Professional ($21) cover on-call for less per user.
