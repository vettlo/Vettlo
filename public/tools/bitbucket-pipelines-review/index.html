What is Bitbucket Pipelines?

Bitbucket Pipelines is the CI/CD built into Atlassian's Bitbucket Cloud, configured in a YAML file in the repo. Free covers 5 users and 50 build minutes a month; Standard ($3.65 per user) includes 2,500 minutes and Premium ($8) 3,500, plus enforced merge checks, deployment permissions and IP allowlisting. Extra minutes are $10 per 1,000.

Who it's best for

Small and mid-size teams that already use Bitbucket for code and Jira for issues.

Why we rank it

It has the lowest per-user price here, and builds, deployments and Jira issues link up without extra setup.

Pros and cons

Strengths

  • Lowest entry price here at $3.65 per user
  • 2,500 build minutes a month on Standard
  • Links builds and deployments to Jira issues

Watch-outs

  • Free plan includes only 50 build minutes
  • Deployment permissions need Premium ($8)
  • Larger runners use minutes faster (a 2x runner counts double)

Skip it if: Your code isn't on Bitbucket.
